## 7. Race

### HUD
左上:
- 順位 3/8
- キャラ名

右上:
- ミニマップ
- 残距離 / セクション

下:
- 葉力ゲージ
- 葉脈炉ボタン
- 臨界カウント
- 耐久

通知:
- 流れに乗った
- 接触
- 特性発動
- 妨害
- WARNING

左下（実況・v1.1 追加）:
- 文字の実況欄。最新の1行を大きく、1つ前の行を小さく残す。自分の葉っぱの話題は左の帯をオレンジにする
- 実況の対象: スタート、先頭の入れ替わり、自分の順位の上下、見せ場区間への突入、ルート選択、接触・姿勢崩れ、葉脈炉（始動・OVER FLOW・解除・故障）、事故・リタイア・ロスト、妨害、最終直線、接戦、ゴール
- まわりの出来事は「先頭争い」と「自分のすぐ前後」だけを拾う。同じ出来事は8秒以内に繰り返さない
- 間隔: 重要（ゴール・炉・事故など）0.8秒 / 通常 2.2秒 / 状況説明 3.6秒以上あける。7秒黙ったら順位の状況を伝える
- シミュレーションの乱数を使わない（同じレースなら同じ実況。実況の有無でレース結果は変わらない）。生成は Application 層の `RaceCommentator`
- 音声の実況はボイス収録にあたるため MVP では行わない（CLAUDE.md §2）

### 葉脈炉起動
画面中央を塞がない。
短いカメラ寄り + 葉脈発光。

### 臨界
- UI振動
- 警告音
- 色変化
- カウント

演出が強くてもキャラの位置を見失わないこと。
