# 05. 育成・親木・接ぎ木仕様

> **v1.1 改訂（2026-10-02 仕様レビュー）** ならしの効果語彙とパラメータの対応表、育成でのLost条件を追記。追記箇所には【v1.1】を付ける。

## 1. 育成思想

「ステータス+3」だけの古典的コマンド育成にしない。

プレイヤーは、
**今日の自然条件を見て、その葉っぱをどんな体質に仕上げるか**
を考える。

## 2. ならし

### 朝露浴
向く:
回復 / 冷却 / 浮力。

体質候補:
瑞々しい。

### 日向ならし
向く:
軽量 / 最高速 / 炉出力。

リスク:
乾燥。

### 風ならし
向く:
姿勢 / 加速 / 横流れ。

特性:
風乗り。

### 小川流し
向く:
基礎流速 / 判断 / 経験。

### 激流ならし
向く:
高速 / 胆力 / 激流適性 / 炉。

リスク:
傷 / 耐久減 / ロスト（極端な条件のみ）。

【v1.1】「極端な条件」= 耐久が危険帯（20未満）かつ 疲労が高疲労閾値（70）以上 の両方。
この場合のみ危険度「極危険」として確認ダイアログを必ず出し、承認後に限りLost判定を行う。それ以外の育成ではLostは発生せず、傷・耐久減まで。

### 渦ならし
向く:
旋回 / 渦耐性。

### 石間抜け
向く:
反応 / 回避。

### ぶつかり稽古
向く:
接触 / 妨害耐性。

性格変化候補:
負けず嫌い / 喧嘩葉。

### 葉脈炉同調
向く:
葉脈炉各能力。

### 休養
疲労・調子回復。

### 2.1 効果語彙 → パラメータ対応表【v1.1】

上記の「向く」には主能力（02 §4）にない語が混在しているため、実装上は以下へ写像する。
UIの表示語は自由だが、内部では必ずこの表のパラメータを増減する。

| 表示語 | 内部パラメータ |
|---|---|
| 最高速 / 基礎流速 / 高速 | stats.flowSpeed |
| 加速 / 軽量 / 旋回 | stats.acceleration |
| 浮力 | stats.buoyancy |
| 姿勢 / 回避 / 接触 | stats.stability |
| 頑丈（旧: 耐久） | stats.toughness |
| 判断 / 反応 / 経験 | stats.judgement |
| 胆力 / 激流適性 | affinity.rapid |
| 渦耐性 | affinity.whirlpool |
| 狭所 | affinity.narrow |
| 炉 / 炉出力 | furnace.output（同調系は furnace.* 各能力） |
| 冷却 | furnace.cooling |
| 回復 | fatigue 減少 / 調子上昇（能力ではない） |
| 妨害耐性 | stats.stability ＋ 体質累積 collisionExperience |
| 乾燥 / 瑞々しい 等 | 体質累積値（§4） |

※ スクリーンサンプル画像の「旋回」「胆力」は上表で読み替える。

## 3. 成長結果

1回のならしで決めるもの:

```text
baseGrowth
x growthPhase
x talent
x weatherAffinity
x condition
x fatiguePenalty
x randomRange
```

加えて:
- trait event
- body type shift
- visual change
- injury

## 4. 体質

隠れ累積値を持つ。

例:
- moisture
- dryness
- toughness
- rapidExperience
- collisionExperience
- furnaceStress

閾値で体質を獲得。

例:
`dryness >= 70 -> 乾き葉`

体質は完全な上位互換にしない。

## 5. おまかせ育成

方針:
- スピード
- 安全
- 耐久
- 葉脈炉
- 急流
- 妨害

AIが危険度上限を守って育成。

ユーザー設定:
- 安全第一
- 標準
- 攻める

## 6. 親木

各ランナーは「葉統」に属する。

引退した優秀個体の実績から「継承因子」を親木系統へ登録できる。

「葉っぱそのものが生殖する」という表現にはしない。

世界観上:
**葉っぱが残した流れ・葉脈の記憶を親木が受け取り、次の若葉へ伝える。**

## 7. 接ぎ木

親木A + 親木B。

継承候補:
- 基礎能力レンジ
- 成長型
- 適性
- 葉脈炉
- 性格傾向
- 因子

候補3体を生成。

### 生成
各能力:
- Parent A contribution
- Parent B contribution
- species bias
- mutation
- random variance

## 8. 因子

因子例:
- 高速葉脈
- 長時間臨界
- 強冷却
- 急流巧者
- 雨巧者
- 高浮力
- 強靭
- 接触巧者

1個体に主要因子2〜4程度。

全部継承しない。

## 9. 突然変異

低確率。

- 二重葉脈
- 黄金
- 黒葉
- 斑入り
- 特殊シルエット

「レア = 必ず強い」にしない。

例:
二重葉脈:
出力 +++
炉耐久 --

## 10. 引退 vs 続投

引退:
因子を安全に登録。

続投:
記録を伸ばせる。
ロストすると一部の後天因子登録チャンスを失う。

この葛藤を重要なゲーム性とする。
